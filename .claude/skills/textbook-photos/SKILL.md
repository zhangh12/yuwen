# 课本照片 → yuwen 课文（yuwen-pages JSON）

用 Claude Code 自带的看图能力，把课本照片里的**正文汉字**提取出来，组成一篇课文（每张照片一页），写成 yuwen 可导入的 JSON。yuwen 会自己给汉字注音（含按词定音的多音字处理），所以**只要汉字正文，不要照片里印的拼音**。

yuwen 的内容层次是 课本 → 课文 → 页面；本技能的默认假设：**一次处理 = 一篇课文**（同一课的多张照片是它的多页）。

## 1. 确定输入、格式转换与顺序

用户会给出图片来源，可能是单张/多张图片路径或一个文件夹（处理其中所有图片）。

**格式转换（重要）**：Read 工具只能看 `.jpg/.jpeg/.png/.webp`，**打不开 `.heic`**。对 HEIC（及其它读不了的格式），先用 macOS 自带的 `sips` 转成 JPG 再 Read：

```bash
sips -s format jpeg "输入.HEIC" --out "/tmp/输出.jpg"
```

**顺序**：优先用照片中可见的**课号/页码**确定页面先后；没有时再按文件名自然排序（用户给出的路径顺序不一定是阅读顺序）。

**朝向**：手机照片常被旋转 90°、文字横躺——照常识读即可，不影响提取。

**跨多课**：若照片明显属于**多篇课文**（出现多个课号/标题），按课拆分：逐课确认后分别产出存档文件；`inbox.json` 一次只放一课（放最后确认的那课，其余提示用户在 yuwen 里用页面栏「导入」逐个存档文件导入）。

## 2. 逐张识别正文

对每张图片用 **Read 工具**查看，提取正文，严格遵守：

1. **只输出简体汉字与中文标点**（，。！？；：、“”‘’《》—…等）。
2. **完全忽略拼音注音**：汉字上方/旁边的拼音字母一律不要输出。
3. **保留分段**：自然段之间用一个换行符 `\n` 分隔。
4. **不要**输出课号、页码、书眉/书脚、练习题编号、插图说明、旁注气泡/小贴士等非正文内容（除非用户另有要求）。
5. 个别字识别不确定时，结合上下文给出最可能的汉字，**不要**用拼音或 `?` 占位；确有存疑的，在交付时单独列出提醒用户核对。

**每张照片 = 一页**；课文标题取照片中可见的课文标题，或正文开头几个字。页标题可省略（yuwen 会取正文开头）。

## 3. 写出文件（双写）

结果 JSON 格式**必须**为：

```json
{
  "format": "yuwen-pages",
  "version": 1,
  "id": "<唯一字符串，如 ip-20260702-153000>",
  "title": "<课文标题，如 青蛙写诗>",
  "pages": [
    { "title": "春晓", "text": "春眠不觉晓，\n处处闻啼鸟。" }
  ]
}
```

- `id` **必填且每次生成都要不同**（建议 `ip-<日期>-<时分秒>`）：yuwen 靠它判断收件箱里是不是新内容。
- `title` 是**课文名**（yuwen 一键导入时用它命名新课文）。
- `pages[].text` 为该页正文，段落用 `\n` 分隔；`pages[].title` 可选。

**写两份**：

1. **收件箱**：仓库根 `inbox.json`（覆盖旧内容即可，已在 .gitignore 中）——yuwen 会自动发现它。
2. **存档**：源照片目录下 `yuwen-<课文名>.json`——便于日后重复导入或备份。

写完后**用 `node -e "JSON.parse(...)"` 校验能解析**再交付。

## 4. 交付

告诉用户：

> **切回 yuwen 的浏览器标签页**（或刷新一次）——yuwen 会自动发现收件箱里的《课文名》，弹出提示，一键选择「新建为课文」（放进当前课本）或「追加到当前课文」。无需找文件、无需文件选择器。

备用路径（比如用户想稍后导入别的存档）：yuwen 页面栏「导入」选存档 JSON，追加进当前课文。

如有识别存疑的字，一并列出请用户核对。
