# 课本照片 → yuwen 页面（yuwen-pages JSON）

用 Claude Code 自带的看图能力，把课本照片里的**正文汉字**提取出来，每张照片作为讲义的一页，写成一个 yuwen 可导入的 JSON 文件。yuwen 会自己给汉字注音，所以**只要汉字正文，不要照片里印的拼音**。

## 1. 确定输入、格式转换与顺序

用户会给出图片来源，可能是：
- 单张图片路径；
- 多张图片路径；
- 一个文件夹（处理其中所有图片）。

**格式转换（重要）**：Read 工具只能看 `.jpg/.jpeg/.png/.webp`，**打不开 `.heic`**。对 HEIC（以及其它读不了的格式），先用 macOS 自带的 `sips` 转成 JPG 再 Read，例如：

```bash
sips -s format jpeg "输入.HEIC" --out "/tmp/输出.jpg"
```

**顺序**：优先用照片中可见的**课号/页码**确定页面先后；没有时再按文件名自然排序（用户给出的路径顺序不一定就是阅读顺序）。

**朝向**：手机照片常被旋转 90°、文字横躺——照常识读即可，不影响提取。

## 2. 逐张识别正文

对每张图片用 **Read 工具**查看，提取正文，严格遵守：

1. **只输出简体汉字与中文标点**（，。！？；：、“”‘’《》—…等）。
2. **完全忽略拼音注音**：汉字上方/旁边的拼音字母一律不要输出。
3. **保留分段**：自然段之间用一个换行符 `\n` 分隔。
4. **不要**输出课号、页码、书眉/书脚、练习题编号、插图说明、旁注气泡/小贴士等非正文内容（除非用户另有要求）。
5. 个别字识别不确定时，结合上下文给出最可能的汉字，**不要**用拼音或 `?` 占位；确有存疑的，在最后单独列出提醒用户核对。

**每张图片 = 一页**；页标题取照片中可见的课文标题，或正文开头几个字。
**同一课跨多张照片时**（后一张没有新课号、正文紧接上一张）：默认仍按"每张一页"，但要在交付时提示用户，并询问是否需要合并成一页。

## 3. 写出 yuwen-pages 文件

把结果写成 JSON 文件（默认写到**源照片所在目录**下的 `yuwen-导入.json`，或用户指定的路径；交付时报告**绝对路径**）。写完后**用 `node` 跑一次 `JSON.parse` 确认能解析**再交付。格式**必须**为：

```json
{
  "format": "yuwen-pages",
  "version": 1,
  "pages": [
    { "title": "春晓", "text": "春眠不觉晓，\n处处闻啼鸟。\n夜来风雨声，\n花落知多少。" },
    { "text": "小河弯弯，流过田野，流向远方。" }
  ]
}
```

- `format` 固定为 `"yuwen-pages"`，`version` 为 `1`（yuwen 据此校验）。
- `pages` 顺序与图片顺序一致。
- `pages[].text` 是该页正文，段落用 `\n` 分隔。
- `pages[].title` 可选；省略时 yuwen 会用正文开头几个字。

可参考项目根目录的 `示例-导入页面.json` 作为格式样例。

## 4. 交付

告诉用户生成的文件路径，并说明导入方式：

> 在 yuwen 左侧「页面」栏点「导入」→ 选这个 JSON 文件 → 各页会**追加到当前讲义**，之后在 yuwen 内微调（改多音字、调颜色、配图等）。

如有识别存疑的字，一并列出请用户核对。
