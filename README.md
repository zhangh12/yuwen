# yuwen

`yuwen` 是一个面向低年级学生的中文汉字讲义编辑器。它把**讲义编辑**与**课堂展示**放在同一个界面里，围绕汉字、拼音、例词/例句、配图与页面式讲义组织，帮助老师/家长快速做出可讲、可练、可打印的语文材料。

内容按三级层次组织：**课本 → 课文 → 页面**。一本课本包含多篇课文，一篇课文包含多页。一次只打开一篇课文进行阅读或编辑；导出（查字、备份）时可以跨课文、跨课本选择更大范围。

零构建、零依赖、无后端：原生 ES module，克隆下来起一个静态服务器就能用；全部数据保存在本机浏览器中。

> 本文是**使用说明**。设计、架构与开发约定见 **[DEVELOPMENT.md](DEVELOPMENT.md)**。

## 运行

需通过本地服务器访问（原生 ES module 不能用 `file://` 直接打开）：

```bash
npm start          # 等价于 python3 -m http.server 5173
# 然后访问 http://localhost:5173
```

macOS 亦可双击 **「启动 yuwen.command」**：自动起服务器并打开浏览器。

顶栏 brand 处显示当前版本号（如 `yǔwén · v0.8.2`）。若怀疑浏览器没加载到最新代码，先硬刷新（`Cmd+Shift+R`）再看版本号。

## 界面速览

- **顶栏**：左起 上一课/下一课、查字，拼音 / 字库例句 / 字号 / 全文页 / 朗读 / 清色 / 最大化；最右侧是「课本」「目录」与面包屑「课本 › 课文」（面包屑弹性伸缩，切换课文时所有按钮位置不变）。
- **左侧页面栏**：当前课文的页面列表。
- **主区（普通页）**：左上正文、左下例词例句、右侧配图，比例约 正文 70% / 图片 30%，三块尺寸固定、点不同字不跳版。

## 课本与课文

- 顶栏「课本」打开两级导航（课本 → 课文的手风琴）。点课文即打开；任一课本都可展开/收起，当前课本默认展开。
- 弹层顶部：「备份」「导入」「新建书」。
- 顶栏「目录」只列**当前课本**的课文（带序号与页数，当前课文高亮），点击即跳转——比两级导航更快的课内切换。
- 顶栏「‹ 上一课」「下一课 ›」在当前课本内前后翻课文，到头置灰。
- 新建课文：课本行内 `+`，或课本右键「新建课文」。
- 重命名 / 复制 / 删除走右键菜单（课本与课文各有一套）。
- 护栏：至少保留一本课本；每本课本至少保留一篇课文。

## 页面

- `+` 新增页面：插在**当前页后面**，并自动滚动到可见位置。
- 「导入」从 `yuwen-pages` JSON 批量导入页面到当前课文（字号按实际渲染自动测定）。
- **多选**：普通点击＝单选；`Shift`＝选区间；`Cmd/Ctrl`＝增减单页。选中的页面（含单选）带边框。条目可键盘聚焦，`Enter/空格` 打开。
- 右键菜单：打印页面 / 复制页面 / 复制到课文… / 移动到课文… / 删除页面；多选（≥2 页）时各项针对整个选区（「打印选中的 N 个页面」等）。删除有确认；**删空整册会自动补一张空白页**。
- **复制到课文 / 移动到课文**：把选中的页面送到任一课本里某篇课文的尾部，或就地「＋ 新建课文…」（自己命名；默认展开当前课本，也可展开别的课本）。移动＝送达后从本课文删除（移空自动补空白页）；操作完停留在原课文，方便连续切割。跨课本时，页面引用的例句/配图素材会自动跟到目标课本。
  - 典型工作流：一批课本照片一次识别、导成一篇长课文，再在 yuwen 里多选页面逐段「移动到课文」，切割成一篇篇独立课文。
- 拖拽重排，目标位置显示插入指示线。

## 正文

- **双击正文区**进入编辑；点页面其余任何地方（或失焦）即保存退出。编辑态保留浏览器原生 `Cmd/Ctrl+Z` 撤销。
- **划选复制**：按住鼠标划选若干字，选区不会被打断；此时右键是浏览器原生菜单（可复制）。
- `A- / A0 / A+` 调字号（0.7–1.9，`A0` 复位）。字号是纯粹的字号控制，同一档在任何页面上大小一致。
- **全文页**开关：当前页变成整块只显示正文（无例句区、无图片区），适合整段展示或朗读；仍支持上色与切读音。

## 拼音

- 工具栏「拼音」开关显隐（**默认关**，按课文记忆）；拼音显示在字上方。
- **多音字按词定音**：自动把某字所在的相邻汉字组合（四字→三字→二字，长词优先）拿去查离线词典（2.3 万条），命中则用词典读音——「银**行**→háng」「**长**大→zhǎng」「**为**什么→wèi」「一唱一**和**→hè」；无词可匹配时用常用读音。
- 多音字拼音带下划线，点它可切换候选读音，只改当前这个位置。**手动选过的读音永远优先**，不会被词典覆盖。

## 颜色标注

- 右键点字 → 菜单里选色；该色随即成为「连续标注色」，按住 `Option/Alt` 点其他字快速上同色（再点同一个字可还原）。
- 工具栏「清色」一键清除本页全部颜色；右键菜单可清单字颜色。

## 例词例句与配图

- 左键选中某字后：左下显示它的例词/例句，右侧显示它的配图；未选中字时右侧显示页面配图。
- 例句悬浮按钮：新增 / 上一条 / 下一条 / **读**（朗读）/ **藏**（只在当前位置隐藏）/ **删**（从课本共享素材删除）/ **提示词**（生成配图提示词并复制，可粘给 AI 绘图工具）。
- **素材按课本共享**：同一课本内不同课文里「字+读音」相同的例句与配图共用一份；隐藏是位置级的、互不影响。
- **字库例句**开关（默认关）：某字尚无用户例句时回落显示内置字库释义（只读、可翻页、可朗读）。
- 配图：`+` 选图（存于本机）、可删除/隐藏、右下圆点拖拽调整大小；图片说明点按编辑。

## 朗读

- **整页/选段**：工具栏「朗读」——没选文字读整页；先划选一段字则只读选中部分。
- **例句**：例句区「读」按钮。**单字**：右键菜单「朗读」。
- 语音用浏览器内置 TTS，自动优先增强/自然中文音色。macOS 可在 系统设置 → 辅助功能 → 朗读内容 下载更高质量的中文声音（如「婷婷（高级）」），yuwen 会自动选用。

## 最大化（展示模式）

- 隐藏全部工具界面，只留当前页。`← ↑ PageUp` 上一页；`→ ↓ PageDown 空格` 下一页；点「显示控制栏」退出。

## 从课本照片导入（收件箱）

浏览器本身不识别照片。把课本照片交给随仓库附带的 Claude Code 技能 `textbook-photos`：它识别正文汉字（忽略照片上印的拼音）、每张照片作一页（一次处理＝一篇课文），并把结果写进仓库根的 **`inbox.json`（收件箱）**。

然后**切回 yuwen 的浏览器窗口**——yuwen 在启动和窗口获焦时自动检查收件箱，发现新内容立即弹出提示，四个选项：

1. **新建为课文**（放进当前课本，以课名命名）
2. **追加到当前课文**
3. **稍后再说**（下次回到 yuwen 时再提醒）
4. **忽略此文件**（按 `id` 记住，不再提示）

无需找文件、无需文件选择器。技能同时在照片目录留一份存档 JSON，页面栏「导入」可随时手动导入。

## 查字：汇编 Word 文档与练字帖

顶栏「查字」打开四步向导，把多本课本/多篇课文中的字汇编成可打印材料：

1. **选课文**：课本→课文两级勾选树（勾课本＝整本，三态框）。
2. **选部首**：基于所选课文实际出现的部首（带字数）。
3. **选单字**：默认全选，点字增减；排序三档——首次出现 / 词频 / 部首。
4. **预览导出**：按部首分节，同句多字合并成一条，字标红，可含拼音（默认不含）。

导出：**打印 / 导出 Word**（`.docx`，宋体，Pages 可直接打开）；**导出字帖**——选中的去重唯一字生成米字格练字帖（首格整字 → 逐笔演示 → 整行描红），新窗口打印或存为 PDF。

**打印页面**：页面栏右键某页 → 「打印页面」，直接进入选字步——只列当前页的字、按首次出现排序、默认全不选，选完同样导出 Word 或字帖。多选若干页（`Shift` / `Cmd/Ctrl`）后右键 → 「打印选中的 N 个页面」，一次汇集所选各页的字。

## 备份与导入

课本弹层顶部：

- **备份**：勾选课本/课文（两级树，默认全选）→ **每本课本各导出一个 JSON**。整本备份带全部素材；只选部分课文时只带引用到的素材。跨 N 本 = N 个文件。
- **导入**：可一次选多个备份 JSON。多文件 → 各自新建为课本；单文件 → 选择「作为新课本导入」或「插入到某本现有课本」（素材按「字+读音」合并）。兼容旧版单册导出。

备份文件自包含（含图片），换机器、换浏览器均可完整恢复。
