# yuwen

`yuwen` 是一个面向低年级学生的中文汉字讲义编辑器原型。它把讲义编辑和课堂展示放在同一个界面里，重点支持汉字、拼音、例词/例句、配图和页面式讲义组织。

## 运行

应用使用原生 ES module（`<script type="module">`），需要通过本地服务器访问，不能用 `file://` 直接打开 `index.html`：

```bash
python3 -m http.server 5173
```

然后访问 `http://localhost:5173`。

当前版本不依赖构建工具。讲义数据保存在浏览器 `IndexedDB` 中（`localStorage` 作为兼容旧版本的迁移来源与兜底）。

## 检查

```bash
npm run check
```

该命令检查所有源码模块和本地字库包装脚本的 JavaScript 语法。

## 文件结构

- `index.html`：应用入口。
- `src/main.js`：启动装配（加载状态 → 绑定事件 → 首次渲染）。
- `src/core.js`：常量、拼音查询、状态与数据模型（数据层，无 DOM）。
- `src/storage.js`：持久化（IndexedDB 主存、localStorage 兜底）与讲义 JSON 导入/导出。
- `src/render.js`：界面渲染，持有 `#app` 根元素。
- `src/events.js`：事件委托与全部交互/数据操作逻辑。
- `styles.css`：界面样式。
- `vendor/data-chars.js`：从 `zdict.js` 下载的原始字库数据（仅作存档，运行时不加载）。
- `vendor/data-chars-local.js`：浏览器实际加载的本地字库包装文件。
- `启动 yuwen.command`：macOS 上双击即可启动本地服务器并打开浏览器的便捷脚本。

## 架构与设计

模块为单向依赖、无循环：`core ← storage`、`core ← render`、`core / render / storage ← events`、全部 `← main`。

- **数据层（`core.js`）**：不接触 DOM，便于推理与测试。集中存放常量、拼音/字库查询、全局 `state`，以及讲义/页面/汉字的数据模型与上下文助手。
- **渲染模型（`render.js`）**：`render()` 一次性用模板字符串重建 `#app.innerHTML`。所有插入的用户文本都经 `escapeHtml` 转义。渲染是纯函数式的“按当前 state 重画”，不做局部 DOM diff。
- **事件模型（`events.js`）**：监听器只在启动时**一次性委托绑定**到持久的 `#app`（及 `document`）上。因为 `render()` 只替换 `#app` 的子树、`#app` 本身不变，委托监听器对所有动态节点持续有效，渲染不再重复绑定。单个点击分发器按 `action → 拼音 → 汉字 → 讲义 → 页面 → 空白/画布` 的优先级路由，以复刻原有的冒泡与 `stopPropagation` 语义。
- **数据流**：交互 → 修改 `state` → `saveState()` → `render()`。`saveState()` 把状态写入 IndexedDB（并尽力镜像到 localStorage），是“即改即存”。

### 状态结构

```
state.decks[]            讲义
  └ pages[]              页面
      ├ mainText         正文（唯一真源）
      ├ tokens[]         由 mainText 派生的汉字 token（含 index、拼音、颜色、局部索引…）
      └ images[]         页面配图
  └ lexicon{字|拼音}     讲义内按“汉字+拼音”共享的 { examples, images }
state.activeDeckId / activePageId
state.ui{…}              纯瞬时界面状态（选中、菜单、编辑中、标注、字库翻页…），不持久化
```

`tokens` 始终由 `mainText` 重新分词（`tokenizePage`）得到；正文是唯一真源。共享素材放在 `deck.lexicon`，每个汉字位置只保存指向共享素材的局部状态（停留索引、隐藏列表、颜色、所选读音）。

### 持久化模型

`saveState()` 写入的 payload 为 `{ decks, activeDeckId, activePageId }`：

- **主存 IndexedDB**：库 `yuwen` / 对象仓库 `kv` / 键 `state`，容量远大于 localStorage，可容纳内联图片。
- **localStorage 兜底**：同一 payload 经 `JSON.stringify` 尽力镜像写入；配额超限会被忽略（IndexedDB 为准）。
- **迁移**：启动时若 IndexedDB 无数据，则从旧版本的 localStorage 读取并迁移。
- 导入/导出复用同一 payload 形态。

## 讲义管理

- 顶部工具栏的“讲义”按钮打开讲义选择面板。
- 当前讲义名称显示在顶部工具栏。
- 讲义面板顶部提供「导入」和「新增」两个按钮。
- 讲义重命名、复制、导出、删除通过讲义条目的右键菜单完成。
- 删除讲义会弹出确认。

## 页面管理

- 左侧页面栏显示当前讲义的页面列表。
- 页面栏顶部的 `+` 用于添加页面。
- 页面复制、删除通过页面条目的右键菜单完成。
- 页面可以在列表中拖拽重排，拖动时会在目标位置显示插入指示线。
- 复制页面后会立即切换到复制出的新页面。
- 删除页面会弹出确认。

## 页面布局

普通页面固定为三块区域：

- 左上：正文、汉字、词语、句子或段落。
- 左下：当前选中字对应的例词/例句。
- 右侧：当前选中字对应的图片；如果未选中字，则显示当前页面配图。

三块区域尺寸固定，避免点击不同汉字时页面布局跳动。`A- / A0 / A+` 只影响左上正文区的文字和拼音大小，不改变例句区、图片区或整体画布大小。

## 全文页

顶部工具栏的“全文页”开关可把当前页面切换成全文页面。

全文页特性：

- 整个讲义画布只显示正文。
- 不显示例句区和图片区。
- 点击汉字不会触发例句或图片联动。
- 仍支持右键汉字设置颜色和清除颜色。
- 仍支持按住 Option/Alt 点击汉字连续上色。
- 仍支持点击多音字拼音切换读音。
- 适合展示完整段落或朗读文本。

## 正文编辑

- 顶部工具栏的“编辑正文 / 完成正文”按钮切换编辑模式。
- 编辑模式使用中等大小文本框，不使用展示模式的大字样式。
- 点击空白处或失焦后提交正文修改。
- 文本框内保留浏览器原生 `Cmd/Ctrl+Z` 撤销行为。

## 拼音

- 拼音可通过顶部“拼音”开关显示或隐藏。
- 拼音显示在汉字上方。
- 多音字的拼音使用下划线标记。
- 点击多音字拼音会弹出候选读音列表。
- 单音字拼音点击无响应。
- 选择读音后，只修改当前汉字位置的拼音。

## 字库数据

项目本地保存了 `zdict.js` 的 `js/data-chars.js`：

- 原始文件：`vendor/data-chars.js`
- 浏览器包装文件：`vendor/data-chars-local.js`

应用优先读取 `window.zDictChars` 中的完整数据。如果本地字库加载失败，则使用 `src/core.js` 内置的小型后备表（`FALLBACK_PINYIN`）保证原型仍可运行。

字库中每个字按读音组织了多条释义（如 `长|cháng` 与 `长|zhǎng` 各有一组）。这组释义既用于拼音查询，也作为“字库例句”的内容来源。

## 汉字选择与颜色

- 左键点击正文区汉字：选中该汉字。
- 右键点击正文区汉字：打开汉字操作菜单。
- 右键菜单可设置颜色、清除颜色、朗读单字、添加例词/例句、添加图片。
- “朗读”只读选中的单字（使用浏览器的中文语音）；普通页和全文页都可用。多音字使用语音引擎的默认读音——浏览器 TTS 无法可靠地强制指定某个读音。
- 全文页右键菜单只保留颜色和朗读相关操作。
- 右键设置颜色后，该颜色成为当前连续标注颜色。
- 按住 `Option/Alt` 点击其他汉字可快速应用当前颜色。
- 在同一轮连续标注中，再次按住 `Option/Alt` 点击同一个字，会恢复它上色前的颜色。

颜色面板提供少量高对比颜色，避免复杂调色板。

## 例词和例句

- 选中汉字后，左下区域显示该汉字对应的例词/例句。
- 例句默认以展示状态显示。
- 点击例句文字进入编辑状态。
- 编辑后失焦保存。
- 左下区域悬浮按钮包括新增、上一条、下一条、隐藏、删除和“提示词”。
- “藏”只在当前这个汉字位置隐藏当前例句。
- “删”会从讲义共享素材中删除该例句。
- “提示词”根据当前例句生成一段图片生成提示词并复制到剪贴板，可粘贴到 ChatGPT 等工具生成插画；显示字库释义时则用释义生成，并把占位符“～”替换为该字。
- 例句文字默认黑色。
- 当前选中的汉字如果出现在例句中，会被标红。

## 字库例句

顶部工具栏的“字库例句”开关（默认关闭，按讲义记忆）控制是否在缺少用户例句时回落到字库释义：

- 开启后，点击某汉字时，**若该字尚无任何用户例句**，左下例句区显示字库释义（带“字库”标签，只读），多条可用 `‹ ›` 翻页。
- **一旦用户为该字输入了自己的例句**，立即改回显示用户例句，不再显示字库内容。
- 字库内容按“汉字 + 当前读音”选取；切换汉字或读音时从第一条重新开始。
- 仍可随时用 `+` 添加自己的例句。

## 图片和说明

右侧区域根据选择状态显示不同内容：

- 未选中字：显示当前页面配图。
- 选中字：显示该汉字对应的图片。

图片行为：

- 添加图片会直接打开图片文件选择器。
- 图片可删除。
- 汉字图片可在当前位置隐藏。
- 图片右下角的小圆点可拖拽调整图片大小。
- 图片说明默认以展示状态显示。
- 点击图片说明进入编辑状态。
- 图片说明默认黑色。
- 当前选中的汉字如果出现在图片说明中，会被标红。

## 共享数据规则

同一个讲义内，例词、例句和汉字图片按 `汉字 + 拼音` 共享。

例如：

- `长|cháng` 和 `长|zhǎng` 是两组不同素材。
- 同一讲义内不同页面的 `春|chūn` 共享同一组例句和图片。

每一个具体汉字位置仍保存自己的局部状态：

- 当前停留的例句索引。
- 当前停留的图片索引。
- 在该位置隐藏过的例句 ID。
- 在该位置隐藏过的图片 ID。
- 该位置的颜色。
- 该位置选择的拼音。

## 点击空白处

点击左上正文区域空白处会：

- 提交当前编辑。
- 取消当前选中字。
- 关闭浮层菜单。
- 让右侧回到页面配图。

## 最大化模式

点击“最大化”进入展示模式。

展示模式行为：

- 隐藏顶部工具栏和左侧页面栏。
- 显示当前讲义页面。
- `← / ↑ / PageUp` 切换到上一页。
- `→ / ↓ / PageDown / 空格` 切换到下一页。
- 点击“显示控制栏”退出最大化模式。

## 讲义导入与导出

- 在讲义条目的右键菜单选「导出」，把**该讲义**（含图片）下载为一个 JSON 文件（`yuwen-<讲义名>-<日期>.json`）。每次只导出选定的那一个讲义。
- 讲义面板顶部的「导入」从 JSON 文件读取，并把其中的讲义**追加为新讲义**，不会覆盖现有讲义；导入后切换到新导入的讲义。
- 导入的讲义会分配全新的内部 ID，因此即使重复导入同一文件也不会冲突。
- 导入时会校验文件结构，并丢弃非 `data:image/` 内联图片，避免引入外链或脚本地址。

## 当前限制

- 数据保存在浏览器 `IndexedDB`（突破了 `localStorage` 的容量上限），仍限于单一浏览器，没有云同步。
- 图片以内联 `data:` URL 随讲义一起存储，尚未实现独立资源包格式。
- 朗读功能暂时停用（“朗读”按钮置灰），待发音质量改善后恢复。
- AI 图片搜索/生成尚未接入。
- 目前是静态原型，没有账号、云同步或后端服务。
