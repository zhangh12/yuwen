# yuwen

`yuwen` 是一个面向低年级学生的中文汉字讲义编辑器原型。它把讲义编辑和课堂展示放在同一个界面里，重点支持汉字、拼音、例词/例句、配图和页面式讲义组织。

## 运行

直接在浏览器中打开 `index.html`：

```bash
open index.html
```

也可以用本地服务器：

```bash
python3 -m http.server 5173
```

然后访问 `http://localhost:5173`。

当前版本不依赖构建工具。讲义数据保存在浏览器 `localStorage` 中。

## 检查

```bash
npm run check
```

该命令检查主脚本和本地字库包装脚本的 JavaScript 语法。

## 文件结构

- `index.html`：应用入口。
- `app.js`：讲义状态、渲染和交互逻辑。
- `styles.css`：界面样式。
- `vendor/data-chars.js`：从 `zdict.js` 下载的原始字库数据。
- `vendor/data-chars-local.js`：浏览器可直接加载的本地字库包装文件。

## 讲义管理

- 顶部工具栏的“讲义”按钮打开讲义选择面板。
- 当前讲义名称显示在顶部工具栏。
- 新建讲义通过讲义面板中的 `+` 完成。
- 讲义重命名、复制、删除通过讲义条目的右键菜单完成。
- 删除讲义会弹出确认。

## 页面管理

- 左侧页面栏显示当前讲义的页面列表。
- 页面栏顶部的 `+` 用于添加页面。
- 页面复制、删除通过页面条目的右键菜单完成。
- 页面可以在列表中拖拽重排。
- 复制页面后会立即切换到复制出的新页面。
- 删除页面会弹出确认。

## 页面布局

普通页面固定为三块区域：

- 左上：正文、汉字、词语、句子或段落。
- 左下：当前选中字对应的例词/例句。
- 右侧：当前选中字对应的图片；如果未选中字，则显示当前页面配图。

三块区域尺寸固定，避免点击不同汉字时页面布局跳动。`A- / A0 / A+` 只影响左上正文区的文字和拼音大小，不改变例句区、图片区或整体画布大小。

## 全文页

顶部工具栏的“全文页”开关可把当前页面切换成全文页面。

全文页特性：

- 整个讲义画布只显示正文。
- 不显示例句区和图片区。
- 点击汉字不会触发例句或图片联动。
- 仍支持右键汉字设置颜色和清除颜色。
- 适合展示完整段落或朗读文本。

## 正文编辑

- “编辑正文”位于顶部工具栏。
- 编辑模式使用中等大小文本框，不使用展示模式的大字样式。
- 点击空白处或失焦后提交正文修改。
- 文本框内保留浏览器原生 `Cmd/Ctrl+Z` 撤销行为。

## 拼音

- 拼音可通过顶部“拼音”开关显示或隐藏。
- 拼音显示在汉字上方。
- 多音字的拼音使用下划线标记。
- 点击多音字拼音会弹出候选读音列表。
- 单音字拼音点击无响应。
- 选择读音后，只修改当前汉字位置的拼音。

## 字库数据

项目本地保存了 `zdict.js` 的 `js/data-chars.js`：

- 原始文件：`vendor/data-chars.js`
- 浏览器包装文件：`vendor/data-chars-local.js`

应用优先读取 `window.zDictChars` 中的完整拼音数据。如果本地字库加载失败，则使用 `app.js` 内置的小型后备表保证原型仍可运行。

## 汉字选择与颜色

- 左键点击正文区汉字：选中该汉字。
- 右键点击正文区汉字：打开汉字操作菜单。
- 右键菜单可设置颜色、清除颜色、添加例词/例句、添加图片。
- 全文页右键菜单只保留颜色相关操作。
- 右键设置颜色后，该颜色成为当前连续标注颜色。
- 按住 `Option/Alt` 点击其他汉字可快速应用当前颜色。
- 在同一轮连续标注中，再次按住 `Option/Alt` 点击同一个字，会恢复它上色前的颜色。

颜色面板提供少量高对比颜色，避免复杂调色板。

## 例词和例句

- 选中汉字后，左下区域显示该汉字对应的例词/例句。
- 例句默认以展示状态显示。
- 点击例句文字进入编辑状态。
- 编辑后失焦保存。
- 左下区域悬浮按钮包括新增、上一条、下一条、隐藏和删除。
- “藏”只在当前这个汉字位置隐藏当前例句。
- “删”会从讲义共享素材中删除该例句。
- 例句文字默认黑色。
- 当前选中的汉字如果出现在例句中，会被标红。

## 图片和说明

右侧区域根据选择状态显示不同内容：

- 未选中字：显示当前页面配图。
- 选中字：显示该汉字对应的图片。

图片行为：

- 添加图片会直接打开图片文件选择器。
- 图片可删除。
- 汉字图片可在当前位置隐藏。
- 图片右下角的小圆点可拖拽调整图片大小。
- 图片说明默认以展示状态显示。
- 点击图片说明进入编辑状态。
- 图片说明默认黑色。
- 当前选中的汉字如果出现在图片说明中，会被标红。

## 共享数据规则

同一个讲义内，例词、例句和汉字图片按 `汉字 + 拼音` 共享。

例如：

- `长|cháng` 和 `长|zhǎng` 是两组不同素材。
- 同一讲义内不同页面的 `春|chūn` 共享同一组例句和图片。

每一个具体汉字位置仍保存自己的局部状态：

- 当前停留的例句索引。
- 当前停留的图片索引。
- 在该位置隐藏过的例句 ID。
- 在该位置隐藏过的图片 ID。
- 该位置的颜色。
- 该位置选择的拼音。

## 点击空白处

点击左上正文区域空白处会：

- 提交当前编辑。
- 取消当前选中字。
- 关闭浮层菜单。
- 让右侧回到页面配图。

## 最大化模式

点击“最大化”进入展示模式。

展示模式行为：

- 隐藏顶部工具栏和左侧页面栏。
- 显示当前讲义页面。
- `← / ↑ / PageUp` 切换到上一页。
- `→ / ↓ / PageDown / 空格` 切换到下一页。
- 点击“显示控制栏”退出最大化模式。

## 当前限制

- 数据保存在浏览器 `localStorage`，尚未实现文件导入/导出。
- 图片保存在浏览器数据中，尚未实现独立资源包格式。
- AI 图片搜索/生成尚未接入。
- 目前是静态原型，没有账号、云同步或后端服务。
