# yuwen

`yuwen` 是一个面向低年级学生的中文汉字讲义编辑器。它把**讲义编辑**与**课堂展示**放在同一个界面里，围绕汉字、拼音、例词/例句、配图与页面式讲义组织，帮助老师/家长快速做出可讲、可练、可打印的语文材料。

内容按三级层次组织：**课本（book）→ 课文（text）→ 页面（page）**。一本课本包含多篇课文，一篇课文包含多页。用户一次只打开一篇课文进行阅读或编辑；导出（查字、备份）时才可跨课文、跨课本地选择更大范围。

本文档前半部分是**使用说明**（面向用户），后半部分是**设计与开发**（面向后续开发与代码审阅的出发点）。

# 使用说明

## 运行

原生 ES module，需通过本地服务器访问，不能用 `file://` 直接打开 `index.html`：

```bash
npm start                        # 等价于 python3 -m http.server 5173
# 然后访问 http://localhost:5173
```

macOS 亦可双击 **「启动 yuwen.command」** 自动起服务器并打开浏览器。无需构建、无需安装依赖（`npm start` 只是起静态服务器的快捷方式）。数据保存在本机浏览器中。

## 功能说明

### 课本与课文

- 顶部工具栏「课本」按钮打开**两级导航**（课本 → 课文的手风琴）；顶栏面包屑显示「课本 › 课文」。
- 点课文即打开它（一次只打开一篇进行编辑/展示）。任一课本都可展开/收起；当前课本默认展开。
- 弹层顶部：「备份」「导入」「新建书」。
- **新建**：「新建书」新建课本；每本课本行内 `+` 或课本右键「新建课文」在该本下新增课文。
- 命名、复制、删除通过右键菜单：课本右键＝新建课文 / 重命名课本 / 删除课本；课文右键＝重命名 / 复制 / 删除。
- **护栏**：至少保留一本课本；每本课本至少保留一篇课文（删到最后一篇会被拦下，需删整本课本）。

### 页面

- 左侧页面栏显示**当前课文**的页面列表。
- `+` 新增页面；「导入」从 `yuwen-pages` 文件批量导入页面到当前课文。
- **多选**：普通点击＝单选；`Shift` 点击＝选区间；`Cmd`(macOS)/`Ctrl`(Win) 点击＝增减单页（对齐 Finder/PowerPoint）。页面条目可键盘聚焦，`Enter/空格` 打开。
- 右键菜单：**打印页面…** / 复制页面 / 删除页面；在多选（≥2 页）里右键则是「删除选中的 N 个页面」。删除有确认，且不允许删空整册。
- 页面可拖拽重排，拖动时在目标位置显示插入指示线。

### 普通页布局

普通页固定为三块，尺寸固定、点不同字不跳版：

- **左上**：正文——字、词、句或段落。
- **左下**：当前选中字的例词/例句。
- **右侧**：当前选中字的图片；未选中字时显示当前页面配图。

左右按比例分栏：**正文区 ≈70% / 图片区 ≈30%**（图片区有最小宽度兜底），不随屏宽让图片区无限变大。

### 正文编辑

- 工具栏「编辑正文 / 完成正文」切换编辑模式。
- 编辑态用中等大小文本框（非展示大字）；点空白处或失焦即提交；保留浏览器原生 `Cmd/Ctrl+Z` 撤销。

### 字号

- `A- / A0 / A+` 调节左上正文的字号，范围 0.7–1.9（`A0` 复位为 1）。
- 字号是**纯粹的字号控制**：与内容长短、普通页/全文页无关，同一档在任何页面上实际大小一致。

### 拼音

- 工具栏「拼音」开关显隐；拼音显示在字上方。
- 多音字拼音带下划线，点它弹出候选读音；单音字点无反应。
- 选择读音只改**当前这个汉字位置**的拼音。

### 汉字选择与颜色

- 左键点字＝选中；右键点字＝打开操作菜单（设色 / 清色 / 朗读单字 / 加例词句 / 加图）。
- 右键设色后，该色成为当前「连续标注色」；按住 `Option/Alt` 点其他字快速上同色。
- 同一轮连续标注中再 `Option/Alt` 点同一个字，会还原它上色前的颜色。
- 颜色面板只给少量高对比色。

### 例词与例句（左下）

- 选中字后显示该字的例词/例句；点文字进入编辑，失焦保存。
- 悬浮按钮：新增、上一条、下一条、**藏**、**删**、**提示词**。
  - 「藏」只在**当前这个字位置**隐藏当前例句；「删」从**课本共享素材**中删除该例句。
  - 「提示词」据当前例句（或字库释义）生成一段配图提示词并复制到剪贴板，可粘到 AI 绘图工具。
- 当前选中字若出现在例句中会被标红。
- 素材按**课本**共享：同一课本内不同课文里「字+读音」相同的例词/例句、配图共用一份（详见「素材按课本共享」）。

### 字库例句

- 工具栏「字库例句」开关（默认关，按课文记忆）。
- 开启后，某字**尚无任何用户例句**时，左下回落显示字库释义（带「字库」标签、只读，多条可 `‹ ›` 翻页）。
- 一旦为该字输入了自己的例句，立即切回用户例句。字库内容按「字+当前读音」选取。

### 图片与说明（右侧）

- 未选中字→当前页面配图；选中字→该字配图（按课本共享）。
- 加图直接打开文件选择器；可删除、可在当前位置隐藏；右下小圆点可拖拽调整大小。
- 说明点按编辑、失焦保存；当前选中字出现在说明中会标红。

### 全文页

- 工具栏「全文页」开关把当前页切成整块只显示正文：无例句区、无图片区、无左右分栏，点字不联动。
- 仍支持右键设色/清色、`Option/Alt` 连续上色、点多音字拼音切读音。适合整段展示或朗读。

### 朗读

- **单字朗读**：右键菜单「朗读」，用浏览器中文语音；普通页与全文页均可用。多音字用语音引擎默认读音（浏览器 TTS 无法可靠指定读音）。
- **整页朗读**按钮暂置灰，待发音质量改善再启用。

### 最大化（展示模式）

- 隐藏工具栏与页面栏，只留当前页。
- `← / ↑ / PageUp` 上一页；`→ / ↓ / PageDown / 空格` 下一页。
- 点「显示控制栏」退出。

### 从课本照片导入

浏览器本身不识别照片。用随仓库附带的 Claude Code 技能 `textbook-photos`：把一张/多张课本照片交给 Claude Code，它识别正文汉字（忽略照片上的拼音）、每张作一页，产出一个 `yuwen-pages` JSON；再在页面栏「导入」它即可。HEIC 会先转 JPG，同一课跨多张照片会提示是否合并。

### 按部首查字、导出 Word 与字帖

顶部工具栏「查字」打开四步向导，把多本课本/多篇课文中的字汇编成可打印文档或练字帖：

1. **选课文**：**两级树**——课本可整本勾选（三态勾选框：全选/部分/未选）并展开，课文可单独勾选；勾课本＝选/清该本全部课文。
2. **选部首**：基于所选课文实际出现的部首（带字数），可「全选」（＝不按部首筛）或部分选。
3. **选单字**：列出符合条件的单字（带出现次数），**默认全选**，点字可移除/恢复。排序三档：**首次出现顺序 / 词频 / 部首**（查字默认词频）。
4. **预览导出**：按部首分节（每部首另起一页），同部首内按课文排序；共用同一句的几个字合并为一条（表头列这些字+出处，下一行是例句、这些字标红，可选拼音）。

导出动作：

- **打印 Word / 导出 Word**：上述「字+例句」文档（`查字-<日期>.docx`，宋体，Pages 可直接打开编辑，转 PDF 稳定）。
- **导出字帖**：把选中的**去重唯一字**生成米字格练字帖（新窗口打印 / 存为 PDF）。每字一块：首格整字 → 逐笔（已写笔画灰、当前笔粉红）→ 末尾整行描红；连续田字格、外套粗绿框、跨页补边。字序与 Word 文档中字的出现顺序一致。

### 打印页面

页面栏右键某页 → **「打印页面…」**，直接进入「选择单字」界面：**只列出当前页的所有单字**，默认按**首次出现顺序**全选，可点掉不需要的；再「预览导出 →」导出 **Word** 或**字帖**。完全复用查字的预览与导出，只是范围锁定在这一页。

### 备份与导入

课本弹层顶部：

- **备份**：勾选要备份的课本/课文（同一棵两级树，默认全选），点「备份」→ **每本课本各导出一个 JSON**。整本备份带该课本全部素材；只选部分课文时，只带这些课文引用到的素材。选中跨越 N 本课本＝下载 N 个文件（浏览器一次授权后静默落盘）。
- **导入**：可**一次选多个**备份 JSON。多文件 → 每个各自**新建为一本课本**。单文件 → 弹选择：**作为新课本导入** / **把其中课文插入到某本现有课本**（插入时按「字+读音」合并素材）。兼容旧版单册导出格式。导入只保留 `data:image/` 内联图片。

# 设计与开发

以下面向后续开发与代码审阅：先讲清 yuwen 的设计取舍与不可破坏的约束，再给架构、关键决策理由、数据格式与开发约定。

> 命名提示：代码内部**一篇课文仍称 `deck`**（历史名，早期「讲义」＝现在的「课文」）；`book`（课本）是在其上新加的分组层。`state.activeDeckId` 即「当前课文 id」。UI 文案统一用「课本 / 课文」。

## 给代码审阅者

- **跑起来**：`npm start` → `http://localhost:5173`。测试：`npm test`（node:test，零依赖）+ 浏览器自检页 `test/browser.html`（覆盖真 IndexedDB、注入面、测量排版；会清空本机数据）。全部源码在 `src/`（6 个 ES module）+ `styles.css`。
- **读代码的顺序**：`core.js`（数据模型，无 DOM）→ `storage.js`（持久化/迁移/备份）→ `render.js`（全量 innerHTML 渲染）→ `events.js`（一次性委托的全部交互）。`charquery.js`/`zitie.js` 是独立的导出功能。
- **重点核对的不变式**：① 所有模板经自动转义的 `html` 标签模板拼装、插值默认转义（XSS 面：搜索 `rawHtml` 的少数放行点）；② 导入路径只接受 `data:image/` 内联图片（`storage.js` 的 `sanitizeEnvelope`）；③ 旧版 `decks[]` 存档的迁移不丢数据（`normalizeToBooks`/`ensureBookModel`）；④ `mainText` 是唯一真源，`tokens` 一律重新派生；⑤ 备份「一个 JSON = 一本课本」。
- **已知取舍**（非缺陷）：全量重画不做 diff；`deck`＝课文的历史命名；字帖笔画数据来自 CDN；详见「关键设计决策与理由」。

## 设计重点

这些取舍驱动一切实现，改动前请先对齐：

1. **三级层次、一次只开一篇课文**：课本 → 课文 → 页面；编辑/展示始终针对单一「当前课文」（`activeBookId + activeDeckId`）。正因如此，整个编辑与渲染面几乎不随层次化而改，改动集中在**导航、查字选择、备份/导入**四处。
2. **编辑即展示**：同一套页面既是编辑器也是投屏材料，任何编辑态都应能一键进入干净展示态（最大化 / 全文页），布局不跳动。
3. **零构建、纯静态、本地优先**：原生 ES module，浏览器直接加载，无打包、无框架、无后端，数据留在本机。新增能力尽量守住「克隆即用、`http.server` 就能跑」。
4. **正文是唯一真源**：页面只存 `mainText`，所有汉字 token、拼音、分词都由它实时派生，绝不把派生结果当真源来存。
5. **素材按课本共享**：例词、例句、汉字配图挂在**课本级**词库上按「汉字+读音」共享；每个汉字位置只存指向共享素材的**局部指针**（停留索引、隐藏名单、颜色、所选读音）。多音字天然分组。
6. **布局稳定、字号可控**：普通页三区尺寸固定；`A-/A0/A+` 是与内容无关的纯字号控制（单一基准 `38px × 字号`）。左右按 `7fr : 3fr` 分栏。
7. **内容来源多元、但不引入后端**：手输、课本照片经技能转入、跨课文/课本按部首查字汇编、生成字帖、备份/导入——都在「静态前端 + 本地工具」内完成。

## 架构

### 模块依赖（单向、无环）

```
core  ← storage
core  ← render
core / render / storage ← events
        全部          ← main
```

| 模块 | 职责 |
|------|------|
| `src/main.js` | 启动装配：加载状态 → 绑定事件 → 首次渲染。 |
| `src/core.js` | **数据层，无 DOM**。常量、拼音/字库查询、全局 `state`、课本/课文/页面/汉字数据模型与上下文助手（`getActiveBook`/`getActiveDeck`/`allTexts`/`ensureBookModel`/`mergeLexicon` 等）。 |
| `src/storage.js` | 持久化（IndexedDB 主存 + localStorage 兜底/迁移）、**图片 Blob 仓**（`images` 对象仓 + objectURL 缓存 + 孤儿回收）、备份导出/导入（`yuwen-backup` 封套，导出内联/导入入仓）、`yuwen-pages` 页面导入（排版判定可注入）。 |
| `src/render.js` | 界面渲染，持有 `#app` 根元素；`render()` 全量重画。 |
| `src/events.js` | 事件委托与全部交互/数据操作逻辑。 |
| `src/charquery.js` | 按部首查询与导出（Word `.docx` / 打印）的纯逻辑；可限定到单页（打印页面）。 |
| `src/zitie.js` | 米字格练字帖渲染（笔画数据按需取自 CDN）。 |
| `styles.css` | 界面样式。 |

### 三个核心机制

- **渲染模型**：`render()` 一次性重建 `#app.innerHTML`，不做局部 diff——简单优先。所有模板用**自动转义的 `html` 标签模板**拼装：插值默认经 HTML 转义，只有 `html` 自身产出的 SafeHtml（及其数组）原样拼接——「忘了转义」在结构上不可能。
- **事件模型**：监听器**只在启动时一次性委托绑定**到持久的 `#app`（及 `document`）。`render()` 只替换 `#app` 的子树、`#app` 本身不变，委托对所有动态节点持续有效。单个点击分发器按 `action → 拼音 → 汉字 → 课文 → 课本 → 页面 → 空白/画布` 的优先级路由。
- **数据流**：交互 → 改 `state` → `saveState()` → `render()`。即改即存。

### 状态结构

```
state.books[]                 课本
  ├ title / updatedAt
  ├ lexicon{字|拼音}          课本级共享素材 { examples, images }
  └ texts[]                   课文（代码内部仍称 deck）
      ├ settings{…}           按课文的开关（拼音、字库例句…）
      └ pages[]               页面
          ├ mainText          正文（唯一真源）
          ├ tokens[]          由 mainText 派生的汉字 token（index、拼音、颜色、局部索引、隐藏名单…）
          ├ mainTextScale     字号（0.7–1.9，1 为默认）
          ├ textOnly          是否全文页
          └ images[]          页面配图（只存 blobId 引用，字节在 Blob 仓）
state.activeBookId / activeDeckId / activePageId   当前打开的课本 / 课文 / 页面
state.ui{…}                   纯瞬时界面状态（不持久化：导航展开、右键菜单、查字/备份/导入向导等）
```

`tokens` 始终由 `mainText` 重新分词（`tokenizePage`）。共享素材放 `book.lexicon`，每个汉字位置只存局部指针；`allTexts()` 把所有课本的课文拍平，仅供查字/备份枚举。

### 持久化

`saveState()` 写入 payload `{ version:2, books, activeBookId, activeDeckId, activePageId }`：

- **主存 IndexedDB**：库 `yuwen` / 仓库 `kv` / 键 `state`，容量足以容纳内联图片。
- **图片 Blob 仓**：`images` 对象仓（DB v2）存原生 Blob，state 里只有 `blobId` 引用；启动时预载被引用的 Blob 为 objectURL（渲染同步取用），并按引用集回收孤儿。payload 因此不含图片字节：保存变小几个量级、无 base64 膨胀、innerHTML 不再携带兆级字符串。旧数据的内联 `data:` 图片在加载时自动入仓；无 IndexedDB 环境保留内联回退。
- **localStorage 兜底**：同一 payload **防抖镜像**（400ms 合并连续保存，页面隐藏时冲刷），超过 ~4.5MB 直接跳过、超配额则忽略（均以 IndexedDB 为准）。避免图多的课本每次编辑都付一次全量 `JSON.stringify`。
- **迁移（无损）**：启动时读到旧版扁平 payload `{ decks, activeDeckId, activePageId }`，自动包成**一本默认课本「我的课本」**，各课文的旧 `lexicon` 合并进课本级；新旧两种形状都能读。

## 关键设计决策与理由

新功能容易无意破坏这些取舍，特此记录「为什么」：

- **`core.js` 不碰 DOM**：数据层可独立推理/测试（用 `node` 起 DOM 桩即可跑通启动路径）。新逻辑优先放数据层。
- **保留 `deck`＝课文命名、只加 `book` 层**：一次只打开一篇课文，所以 `getActiveDeck()` 语义不变＝当前课文，编辑/渲染面几乎零改；churn 集中在导航、查字选择、备份/导入。省下一次全局重命名。
- **正文唯一真源 + token 派生**：避免「编辑正文后派生数据不同步」的一整类 bug。重分词时新旧 token 用 **LCS 保序对齐**——编辑（尤其在重复字前插入）后，颜色/所选读音/隐藏名单跟着「同一个字」走，不串位（旧的同字贪心匹配会）。
- **自动转义模板取代人工 `escapeHtml` 约定**：防 XSS 从「靠自觉」变成「结构保证」。
- **图片进 Blob 仓而非内联 base64**：课本照片是真实主载荷，内联让每次保存/渲染都背着全部图片字节。备份文件仍自包含（导出内联回 `data:`、导入重新入仓），格式不变。
- **导入排版＝真实 DOM 测量**（`render.measureAutoLayout`）：用真实版式结构离屏渲染正文（含拼音行高），从 1.2 → 0.7 逐档试、取普通页放得下的**最大**字号，放不下判全文页——短课文自动得到大字。测量偏保守（拼音用宽占位）；`storage.autoLayout` 启发式仅作无 DOM 环境兜底。
- **素材按课本共享**：lexicon 从课文上移到课本。`长|cháng` 与 `长|zhǎng` 是两组；同一课本不同课文里的 `春|chūn` 共享同一组例句/图片；位置级只存指针，删素材与「某处隐藏」互不影响。迁移把旧的各自独立的课文并进一本课本后，它们的同名同音素材开始互通——这是新模型的预期行为。
- **迁移无损**：旧 `decks[]` → 一本默认课本；只重排归属、不动内容；`ensureBookModel`/`ensureDeckModel` 兜底并把遗留的按课文 lexicon 折叠进课本级。
- **备份不变式：一个 JSON = 恰好一本课本**。整本备份带该本全部 lexicon；只选部分课文时，只带这些课文的 token 引用到的 lexicon 切片（按「字+读音」抽取）。跨 N 本课本＝N 个文件——根因是「素材按课本走，跨本素材不能塞进同一个封套」。导入：多文件全部新建课本；单文件可选新建 / 插入现有课本（`mergeLexicon` 按键合并、id 去重）；兼容旧 `{decks}` 格式；只保留 `data:image/` 内联图片（杜绝外链/脚本地址）。
- **查字/打印页面复用同一套逻辑**：`charsInDecks`/`collectMatches` 支持可选 `pageId`（限定单页）与 `radicals=null`（不按部首筛，打印页面要全部字）；「打印页面」＝`scope:"page"` 直接进选字步、默认按首次出现顺序全选，预览/Word/字帖走同一代码。
- **字号单一基准**：`.main-text` 统一 `38px × 字号`，`A-/A0/A+` 在长/短文、普通/全文页下含义一致；「长文」判定只再决定对齐与行高，不再改字号。
- **左右分栏 `7fr : 3fr`**：正文区约 70%、图片区约 30%（图片区 200px 兜底），按比例随屏宽自适应，不让图片区在宽屏无限膨胀。
- **Word 用 `.docx` 而非 RTF**：RTF 在 macOS 会触发「无法验证是否含恶意软件」；`.docx` 可被自带 Pages 直接打开、转 PDF 稳定。`.docx` 由内置极小 ZIP + OOXML 生成器拼装，**零第三方依赖**（备份文件的多文件下载亦无需打包依赖）。
- **PDF 一律走浏览器打印**：字帖/查字文档不生成下载文件，用新窗口打印→「存为 PDF」。字帖里的田字格虚线十字用 **CSS 像素**画（SVG 缩放后是亚像素、会消失）；跨页用 `box-decoration-break:clone` 补边；打印窗口**在点击手势内同步 `window.open`** 避免被弹窗拦截。
- **字帖笔画走 CDN、不打包**：`hanzi-writer-data`（jsdelivr，unpkg 兜底），与本地 makemeahanzi 同格式；整包 20MB+，不入仓库、用时才联网。
- **部首数据离线**：`vendor/data-radicals.js`（make-me-a-hanzi），查字完全本地。
- **课本照片→文字不做后端**：浏览器沙箱无法调用 agent、读磁盘，故照片识别放在 Claude Code 技能 `textbook-photos` 完成，产出 `yuwen-pages` JSON，yuwen 只负责导入。刻意不加本地桥接/后端，守住纯静态。

## 数据格式

**页面导入（`yuwen-pages`）**——供手工或 `textbook-photos` 技能产出，把页面追加进**当前课文**：

```json
{
  "format": "yuwen-pages",
  "version": 1,
  "pages": [{ "title": "春天", "text": "春天来了，\n万物复苏。" }]
}
```

`title` 可选（省略取正文开头几字）；`text` 为正文，段落用 `\n` 分隔。导入时按真实 DOM 测量（`measureAutoLayout`）自动定字号/是否全文页，无 DOM 环境回落启发式。参考 `示例-导入页面.json`。

**备份（`yuwen-backup`）**——一个文件恰好一本课本，供备份/迁移，可重新导入：

```json
{
  "format": "yuwen-backup",
  "version": 2,
  "book": {
    "title": "一年级上册",
    "lexicon": { "春|chūn": { "examples": [], "images": [] } },
    "texts": [ { "title": "课文一", "settings": {}, "pages": [] } ]
  }
}
```

`texts` 为课文数组（`texts.length===1` 即单篇课文的特例）；`lexicon` 为该本引用到的共享素材切片（整本备份即全量）。导入时另兼容旧版 `{ decks:[…], activeDeckId, activePageId }` 单册导出。

## 数据来源

- `vendor/data-chars-local.js`：浏览器加载的本地字库（`window.zDictChars`，来自 `zdict.js`）；每字按读音组织多条释义，供拼音查询与「字库例句」。加载失败回退到 `core.js` 内置小表 `FALLBACK_PINYIN`。
- `vendor/data-chars.js`：原始字库存档，运行时不加载。
- `vendor/data-radicals.js`：字→部首（make-me-a-hanzi），查字用，离线。
- 笔画：`hanzi-writer-data`（CDN，按需），字帖用。
- `.claude/skills/textbook-photos/`：把课本照片识别为 `yuwen-pages` 的 Claude Code 技能。

## 检查与开发约定

```bash
npm run check      # node --check 校验所有源码模块 + 字库包装脚本语法
```

- **守零构建**：能不加依赖就不加；必须加时保证浏览器可直接 `import`、`npm run check` 通过。改完至少跑一次它。
- **模板一律用 `html` 标签模板**（插值默认转义）；确认安全的原始片段才用 `rawHtml`。改动后跑 `npm test`；动到渲染/存储再开 `test/browser.html` 自检。
- **新数据逻辑进 `core.js`（无 DOM）**；渲染进 `render.js`；交互走 `events.js` 的委托分发（新增 `data-action`）。
- **改完走 `save → render`**，不要手动改 DOM 绕过重画。
- **改样式时给 `styles.css` 的引用加版本号**（`index.html` 里 `styles.css?v=N`）以绕开浏览器缓存。
- 字帖/查字等「导出」统一走浏览器打印，不生成下载文件（备份 JSON 导出除外）。

## 当前限制与后续方向

**限制**

- 数据存于单一浏览器的 IndexedDB，无账号/云同步/后端。
- 图片以内联 `data:` URL 随课本存储，尚无独立资源包格式（IndexedDB 即改即存；localStorage 镜像已防抖并对大 payload 跳过）。
- 不支持跨课本移动课文（仅在导入时选目标课本）。
- 整页朗读停用；多音字朗读受浏览器 TTS 限制。
- AI 配图仅生成「提示词」，未接入自动搜索/生成。
- 导入排版按导入时的窗口实测；之后换更小的屏幕展示时个别页可能需手动调小字号。

**可能的后续**

- 跨课本移动/整理课文。
- 资源包格式（图片与课文分离），便于分享与版本管理。
- 更好的语音/朗读（或离线 TTS）。
- AI 配图/例句的实际接入（在不破坏「纯静态」前提下探索）。
